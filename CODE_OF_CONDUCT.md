# Community Code of Conduct

Sanskode welcomes respectful collaboration from learners and contributors of all experience levels.

Expected behavior:

- Be considerate, constructive, and patient with beginners.
- Give actionable feedback about code and ideas, not personal attacks.
- Respect different backgrounds and levels of experience.
- Keep discussions focused on improving the project and its learning experience.

Unacceptable behavior includes harassment, insults, discriminatory comments, doxxing, and deliberately disruptive conduct.

Project maintainers may edit, decline, or remove contributions that do not meet these standards. Report a conduct concern privately to the repository maintainers using GitHub's available reporting options.
